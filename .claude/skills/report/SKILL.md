# 生成比价分析报告

基于 `比价结果数据.csv` 按供应商分组，生成自包含的 HTML 分析报告。

## 执行

运行报告生成脚本：

```bash
python3 .claude/skills/report/gen_report.py
```

脚本会自动完成以下工作：
1. 读取 `比价结果数据.csv`
2. 按供应商分组，分析定价、周期、限额三个维度
3. 生成自包含 HTML 报告（内联 CSS，无外部依赖）
4. 写入 `reports/分析报告-YYYY-MM-DD.html`

运行后告知用户报告路径和概要（供应商排名前三名及总体统计）。

## 评级体系

脚本内置以下评级标准，如需调整请直接修改 `gen_report.py`：

### 定价评级（取供应商最优折合定价）
| 区间 | 评级 |
|------|------|
| < ¥0.1 | 捡漏（警惕额度花不完） |
| ≈ ¥0.1（±0.005） | 实惠 |
| ¥0.1～¥0.5 | 正常价 |
| ≥ ¥0.5 | 噶韭菜 |

### 周期评级（取供应商最优周期）
| 周期类型 | 评级 |
|---------|------|
| 散充（无过期） | 最佳 |
| 月卡/季卡/年卡 | 合适 |
| 周卡 | 还行 |
| 日卡 | 慎之又慎 |

### 限额评级（取供应商最差限额）
| 限额类型 | 评级 |
|---------|------|
| 周期内随便用 | 良心 |
| 仅周限额 | 不太地道 |
| 有日限/5h限额 | 恶犬 |
